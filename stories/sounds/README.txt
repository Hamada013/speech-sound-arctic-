تسجيلات القصص
سجّل كل واحدة وضعها في هذا المجلد بالاسم المكتوب هنا (m4a).
بعد إضافة التسجيلات تُسمع في اللعبة ويظهر زر الإعادة.

=== صوت الهمزة (أ): الْأَرْنَبُ أَمِيرٌ ===
1.m4a = هَذَا أَرْنَبٌ أَبْيَضُ اسْمُهُ أَمِيرٌ  ✓
2.m4a = أَمِيرٌ يَأْكُلُ الْجَزَرَ فِي الصَّبَاحِ  ✓
3.m4a = رَأَى أَمِيرٌ أَسَدًا كَبِيرًا  ✓
4.m4a = أَعْطَى الْأَسَدُ أَمِيرًا أَنَانَاسَةً  ✓
5.m4a = أَكَلَ الْأَرْنَبُ وَالْأَسَدُ مَعًا  ✓

=== صوت الباء (ب): الْبَطَّةُ وَالْبَيْتُ ===
6.m4a = بَطَّةٌ صَغِيرَةٌ تَعِيشُ فِي بِرْكَةٍ  ✓
7.m4a = خَرَجَتِ الْبَطَّةُ تَبْحَثُ عَنْ بَيْتٍ  ✓
8.m4a = رَأَتْ بَقَرَةً بَيْضَاءَ بِجَانِبِ الْبَابِ  ✓
9.m4a = أَعْطَتِ الْبَقَرَةُ الْبَطَّةَ خُبْزًا  ✓
10.m4a = بَاتَتِ الْبَطَّةُ فِي بَيْتِ الْبَقَرَةِ الْجَمِيلِ  ✓

=== صوت التاء (ت): التِّمْسَاحُ وَالتُّفَّاحَةُ ===
11.m4a = تِمْسَاحٌ صَغِيرٌ يَعِيشُ تَحْتَ الشَّجَرَةِ  ✓
12.m4a = رَأَى التِّمْسَاحُ تُفَّاحَةً حَمْرَاءَ  ✓
13.m4a = أَكَلَ التِّمْسَاحُ التُّفَّاحَةَ كُلَّهَا  ✓
14.m4a = جَاءَتْ بِنْتٌ تَحْمِلُ تَمْرًا  ✓
15.m4a = تَقَاسَمَتِ الْبِنْتُ وَالتِّمْسَاحُ التَّمْرَ  ✓

=== صوت الثاء (ث): الثَّعْلَبُ وَالثَّلْجُ ===
16.m4a = ثَعْلَبٌ ثَرْثَارٌ يَعِيشُ فِي الْغَابَةِ  ✓
17.m4a = نَزَلَ الثَّلْجُ ثَلَاثَةَ أَيَّامٍ  ✓
18.m4a = لَبِسَ الثَّعْلَبُ ثِيَابًا ثَقِيلَةً  ✓
19.m4a = وَجَدَ الثَّعْلَبُ ثَمَرَةَ كُمَّثْرَى  ✓
20.m4a = نَامَ الثَّعْلَبُ دَافِئًا فِي ثِيَابِهِ  ✓

=== صوت الجيم (ج): الْجَمَلُ الْجَائِعُ ===
21.m4a = جَمَلٌ جَمِيلٌ يَمْشِي فِي الصَّحْرَاءِ  ✓
22.m4a = جَاعَ الْجَمَلُ وَأَرَادَ جَزَرًا  ✓
23.m4a = جَاءَتْ دَجَاجَةٌ تَحْمِلُ جَزَرًا  ✓
24.m4a = جَلَسَ الْجَمَلُ وَالدَّجَاجَةُ تَحْتَ الشَّجَرَةِ  ✓
25.m4a = أَكَلَ الْجَمَلُ الْجَزَرَ وَشَكَرَ الدَّجَاجَةَ  ✓

=== صوت الحاء (ح): الْحِصَانُ وَالْحَمَامَةُ ===
26.m4a = حِصَانٌ أَحْمَرُ يَعِيشُ فِي حَدِيقَةٍ  ✓
27.m4a = حَطَّتْ حَمَامَةٌ حَزِينَةٌ عَلَى الْحِصَانِ  ✓
28.m4a = الْحَمَامَةُ تَبْحَثُ عَنْ حَبٍّ  ✓
29.m4a = حَمَلَ الْحِصَانُ الْحَمَامَةَ إِلَى الْحَقْلِ  ✓
30.m4a = وَجَدَتِ الْحَمَامَةُ الْحَبَّ وَأَحَبَّتِ الْحِصَانَ  ✓

=== صوت الخاء (خ): الْخَرُوفُ وَالْخَيْمَةُ ===
31.m4a = خَرُوفٌ صَغِيرٌ خَرَجَ مِنَ الْخَيْمَةِ  ✓
32.m4a = خَافَ الْخَرُوفُ مِنَ الْخُفَّاشِ  ✓
33.m4a = رَكَضَ الْخَرُوفُ إِلَى الْمَطْبَخِ  ✓
34.m4a = أَعْطَاهُ الطَّبَّاخُ خُبْزًا وَخِيَارًا  ✓
35.m4a = نَامَ الْخَرُوفُ فِي الْخَيْمَةِ مَسْرُورًا  ✓

=== صوت الدال (د): الدُّبُّ وَالدُّلْفِينُ ===
36.m4a = دُبٌّ كَبِيرٌ يَعِيشُ قُرْبَ الْبَحْرِ  ✓
37.m4a = رَأَى الدُّبُّ دُلْفِينًا يَقْفِزُ  ✓
38.m4a = دَعَا الدُّلْفِينُ الدُّبَّ لِلَّعِبِ  ✓
39.m4a = لَعِبَ الدُّبُّ وَالدُّلْفِينُ بِالدَّلْوِ  ✓
40.m4a = عَادَ الدُّبُّ إِلَى دَارِهِ سَعِيدًا  ✓

=== صوت الذال (ذ): الذِّئْبُ وَالذُّبَابَةُ ===
41.m4a = ذِئْبٌ ذَكِيٌّ لَهُ ذَيْلٌ طَوِيلٌ  ✓
42.m4a = ذُبَابَةٌ أَزْعَجَتِ الذِّئْبَ  ✓
43.m4a = هَزَّ الذِّئْبُ ذَيْلَهُ فَذَهَبَتِ الذُّبَابَةُ  ✓
44.m4a = أَكَلَ الذِّئْبُ الذُّرَةَ اللَّذِيذَةَ  ✓
45.m4a = نَامَ الذِّئْبُ تَحْتَ النَّافِذَةِ  ✓

=== صوت الراء (ر): رِحْلَةُ الْأَرْنَبِ ===
46.m4a = أَرْنَبٌ صَغِيرٌ يَسْكُنُ قُرْبَ النَّهْرِ  ✓
47.m4a = رَكِبَ الْأَرْنَبُ الْقِطَارَ صَبَاحًا  ✓
48.m4a = رَأَى الْأَرْنَبُ نَمِرًا يَرْكُضُ  ✓
49.m4a = رَكَضَ الْأَرْنَبُ إِلَى شَجَرَةٍ كَبِيرَةٍ  ✓
50.m4a = رَجَعَ الْأَرْنَبُ إِلَى بَيْتِهِ وَأَكَلَ الرُّمَّانَ  ✓

=== صوت الزاي (ز): الزَّرَافَةُ وَالزَّهْرَةُ ===
51.m4a = زَرَافَةٌ طَوِيلَةٌ تَعِيشُ فِي حَدِيقَةٍ  ✓
52.m4a = زَرَعَتِ الزَّرَافَةُ زَهْرَةً زَرْقَاءَ  ✓
53.m4a = جَاءَ غَزَالٌ يَزُورُ الزَّرَافَةَ  ✓
54.m4a = أَكَلَا الْمَوْزَ وَالزَّبِيبَ مَعًا  ✓
55.m4a = زَادَتِ الزَّهْرَةُ جَمَالًا كُلَّ يَوْمٍ  ✓

=== صوت السين (س): السَّمَكَةُ السَّعِيدَةُ ===
56.m4a = سَمَكَةٌ صَغِيرَةٌ تَسْبَحُ فِي الْبَحْرِ  ✓
57.m4a = رَأَتِ السَّمَكَةُ سَفِينَةً كَبِيرَةً  ✓
58.m4a = سَأَلَتِ السَّمَكَةُ السُّلَحْفَاةَ عَنِ السَّفِينَةِ  ✓
59.m4a = سَبَحَتَا مَعًا تَحْتَ الشَّمْسِ  ✓
60.m4a = نَامَتِ السَّمَكَةُ سَعِيدَةً فِي الْمَسَاءِ  ✓

=== صوت الشين (ش): الشَّمْسُ وَالشَّجَرَةُ ===
61.m4a = شَجَرَةٌ كَبِيرَةٌ تُحِبُّ الشَّمْسَ  ✓
62.m4a = عُصْفُورٌ بَنَى عُشًّا عَلَى الشَّجَرَةِ  ✓
63.m4a = جَاءَتْ فَرَاشَةٌ تَشْرَبُ مِنْ زَهْرَةِ الشَّجَرَةِ  ✓
64.m4a = أَشْرَقَتِ الشَّمْسُ عَلَى الشَّجَرَةِ وَالْعُشِّ  ✓
65.m4a = شَكَرَتِ الشَّجَرَةُ الشَّمْسَ وَالْعُصْفُورَ وَالْفَرَاشَةَ  ✓

=== صوت الصاد (ص): الصَّقْرُ وَالْعُصْفُورُ ===
66.m4a = صَقْرٌ صَغِيرٌ يَطِيرُ فِي السَّمَاءِ  ✓
67.m4a = رَأَى الصَّقْرُ عُصْفُورًا فِي قَفَصٍ  ✓
68.m4a = صَاحَ الْعُصْفُورُ: أَخْرِجْنِي يَا صَدِيقِي  ✓
69.m4a = فَتَحَ الصَّقْرُ بَابَ الْقَفَصِ  ✓
70.m4a = صَارَ الصَّقْرُ وَالْعُصْفُورُ صَدِيقَيْنِ  ✓

=== صوت الضاد (ض): الضِّفْدَعُ وَالضَّيْفُ ===
71.m4a = ضِفْدَعٌ أَخْضَرُ يَعِيشُ فِي بِرْكَةٍ  ✓
72.m4a = جَاءَ ضَيْفٌ يَزُورُ الضِّفْدَعَ  ✓
73.m4a = قَدَّمَ الضِّفْدَعُ لِلضَّيْفِ بَيْضًا وَخُضَارًا  ✓
74.m4a = ضَحِكَ الضَّيْفُ وَالضِّفْدَعُ كَثِيرًا  ✓
75.m4a = عَادَ الضَّيْفُ فِي ضَوْءِ الْقَمَرِ  ✓

=== صوت الطاء (ط): الْقِطَّةُ وَالطَّبْلُ ===
76.m4a = قِطَّةٌ صَغِيرَةٌ تَعِيشُ مَعَ طِفْلٍ  ✓
77.m4a = الطِّفْلُ يَطْرُقُ عَلَى الطَّبْلِ  ✓
78.m4a = خَافَتِ الْقِطَّةُ وَطَلَعَتْ عَلَى الْحَائِطِ  ✓
79.m4a = أَعْطَى الطِّفْلُ الْقِطَّةَ طَبَقَ حَلِيبٍ  ✓
80.m4a = نَامَتِ الْقِطَّةُ بِجَانِبِ الطِّفْلِ  ✓

=== صوت الظاء (ظ): الظَّبْيُ وَالْمِظَلَّةُ ===
81.m4a = ظَبْيٌ ظَرِيفٌ يَعِيشُ فِي الصَّحْرَاءِ  ✓
82.m4a = نَزَلَ الْمَطَرُ وَأَظْلَمَتِ السَّمَاءُ  ✓
83.m4a = وَجَدَ الظَّبْيُ مِظَلَّةً كَبِيرَةً  ✓
84.m4a = جَلَسَ الظَّبْيُ فِي ظِلِّ الْمِظَلَّةِ  ✓
85.m4a = ظَهَرَتِ الشَّمْسُ فَفَرِحَ الظَّبْيُ  ✓

=== صوت العين (ع): الْعُصْفُورُ وَالْعِنَبُ ===
86.m4a = عُصْفُورٌ صَغِيرٌ عَلَى غُصْنِ شَجَرَةٍ  ✓
87.m4a = رَأَى الْعُصْفُورُ عِنَبًا فِي السَّلَّةِ  ✓
88.m4a = أَكَلَ الْعُصْفُورُ حَبَّةَ عِنَبٍ  ✓
89.m4a = جَاءَتْ نَحْلَةٌ تَعْرِضُ عَلَيْهِ الْعَسَلَ  ✓
90.m4a = عَادَ الْعُصْفُورُ إِلَى عُشِّهِ يُغَرِّدُ  ✓

=== صوت الغين (غ): الْغَزَالُ وَالْغَيْمَةُ ===
91.m4a = غَزَالٌ صَغِيرٌ وَصَدِيقُهُ الْغُرَابُ فِي الْغَابَةِ  ✓
92.m4a = رَأَى الْغَزَالُ غَيْمَةً كَبِيرَةً  ✓
93.m4a = غَطَّتِ الْغَيْمَةُ الشَّمْسَ  ✓
94.m4a = غَنَّى الْغُرَابُ: يَا غَيْمَةُ، اذْهَبِي بَعِيدًا  ✓
95.m4a = غَابَتِ الْغَيْمَةُ وَفَرِحَ الْغَزَالُ وَالْغُرَابُ  ✓

=== صوت الفاء (ف): الْفِيلُ وَالْفَأْرُ ===
96.m4a = فِيلٌ كَبِيرٌ وَفَأْرٌ صَغِيرٌ صَدِيقَانِ  ✓
97.m4a = فَتَحَ الْفَأْرُ فَمَهُ جَائِعًا  ✓

=== صوت القاف (ق): الْقِرْدُ وَالْقَمَرُ ===

=== صوت الكاف (ك): الْكَلْبُ وَالْكُرَةُ ===

109.m4a = وَجَدَ الْكَتْكُوتُ الْكُرَةَ وَأَعَادَهَا  ✓

=== صوت اللام (ل): اللَّيْمُونَةُ الصَّفْرَاءُ ===

118.m4a = اشْتَرَتْ مَهَا مَوْزًا وَتَمْرًا  ✓
119.m4a = أَعْطَتْ مَهَا مَوْزَةً لِلْحَمَامَةِ  ✓

=== صوت النون (ن): النَّحْلَةُ النَّشِيطَةُ ===

123.m4a = نَادَاهَا النَّسْرُ: انْهَضِي يَا نَحْلَةُ  ✓
124.m4a = نَهَضَتِ النَّحْلَةُ وَصَنَعَتِ الْعَسَلَ  ✓

=== صوت الهاء (ه): الْهُدْهُدُ وَالْهَدِيَّةُ ===
126.m4a = هُدْهُدٌ جَمِيلٌ وَهِرَّةٌ صَغِيرَةٌ صَدِيقَانِ  ✓
