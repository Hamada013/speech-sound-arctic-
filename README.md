# Speech sound articulation

Arabic articulation practice for children aged 3 to 6, by Ahmad Ghanem (speech and language pathology).

- **نطقي — words**: `words/index.html`. An offline installable game: 28 sounds, 30 words each, in three worlds.
- **المقاطع — syllables**: `syllable/syllable.html`. The syllable train, with mouth animations for every CV syllable.

Everything runs in the browser with no server and no account outside the device. Published with GitHub Pages by `.github/workflows/pages.yml`.

Checks: `node syllable/tests/model.mjs`; browser checks in `words/tests/` and `syllable/tests/` need Playwright.
